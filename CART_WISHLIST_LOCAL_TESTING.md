# Cart and Wishlist — Local Testing

This is the complete cloned HV Vertex website with the Cart and Wishlist frontend task integrated.

## Included changes
- Dedicated cart page with quantity controls, remove controls, clear-cart action, and order summary.
- Dedicated wishlist page with remove and add-to-cart actions.
- Temporary Add to Cart confirmation feedback (about 1.8 seconds where supported).
- Existing website files and dependencies retained from the supplied updated clone.

## Run locally
1. Extract the ZIP.
2. Open the `Hv--ecommerce--main` folder in a terminal.
3. Run `npm install` (or `npm ci` if you prefer the lockfile).
4. Run `npm start` and open the local URL shown in the terminal.

A production build and browser interaction test were not run in this environment.
